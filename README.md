# FinControl

Приложение для учёта личных финансов: веб-интерфейс на JavaScript и Vite,
синхронизация через Firebase и Android-проект на Capacitor.

## Локальный запуск

1. Установите зависимости: `npm ci`.
2. Скопируйте `.env.example` в `.env.local` и заполните настройки своего
   Firebase-проекта.
3. Запустите приложение: `npm run dev`.

Сборка веб-приложения: `npm run build`. Просмотр сборки: `npm run preview`.
Исходники Android находятся в `android/`.

В репозиторий не включены локальные настройки, ключи подписи, зависимости
и результаты сборки. Личные финансовые данные не входят в исходный код.
